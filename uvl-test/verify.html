Verifying a draw

This page is being written (spec §17.4). What is already true and usable:

With the CLI verifier

Every draw folder is plain files in the public repository. Download the folder and run the verifier — the copy frozen inside the folder at seal, or the current one from the site root:

node uvl-verify.cjs <draw folder>

Exit codes: 0 everything reproduced · 1 a published claim does not reproduce · 2 something could not be checked (which is never reported as fine).

Download over HTTPS (repository tarball or raw files) rather than git clone — Git on Windows may translate line endings on checkout, which changes bytes and fails honest hashes unless the repository's .gitattributes is respected.

Without our verifier

The full instruction — recomputing every step with nothing but a shell and any SHA-256 tool, per ticket policy, with a worked test vector — lands here before the first real draw. The derivation in one line until then: winner = highest SHA-256(SHA-256(drawId:randomness):ticketUrl) over the sealed ticket list.
